# homebrew-tap

Homebrew formulae for [mi11ione](https://github.com/mi11ione)'s tools.

```sh
brew install mi11ione/tap/iris
```

| formula | what it is |
|---|---|
| `iris` | Pure-Swift ARM64/ARM64E disassembler with a semantic layer validated against LLVM ([repo](https://github.com/mi11ione/iris)) |
| `swiftfilt` | Swift demangler you can pipe, script, and embed — `c++filt` for Swift ([repo](https://github.com/mi11ione/swiftfilt)) |

Formulae pour prebuilt binaries from each project's GitHub Releases and
verify their checksums.
